# Welcome to my profile

I'm Morgane, a french 21 years old developper. I mostly code in C/C++, with some Java and typescript here and there. I use NixOS as my main distro for desktop and server usage.

I started coding in 2017, my pronouns are they/them, and I studied in system administration (managing servers, deploying software, and so on...) although I am mostly self-taught.

I speak french and english, and I am currently learning spanish.
